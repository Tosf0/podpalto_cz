# Handoff

Předávací poznámky mezi námi. Jeden soubor = jedno předání.

**Název:** `RRRR-MM-DD-NN-tema.md`, např. `2026-11-18-01-export-do-supabase.md`.
`NN` je pořadí v daném dni (01, 02, …), takže se soubory řadí chronologicky.

**Obsah:** od koho a pro koho, větev a commity, co je hotové, co je potřeba rozhodnout
(konflikty) a jak pokračovat. Vyřešené body se v souboru nepřepisují: rozhodnutí se zapíše
do `docs/TODO.md` nebo do specu a případně do dalšího handoffu.
